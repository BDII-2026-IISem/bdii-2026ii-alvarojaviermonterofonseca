## Motores cubiertos

- MySQL 8.0
- PostgreSQL 17
- Microsoft SQL Server 2022
- Oracle Database XE 21c

## Requisitos

Las guías están pensadas para Ubuntu/WSL con Docker y Docker Compose instalados. No subas archivos `.env` ni credenciales reales a GitHub.
